# 🛍️ E-Commerce Web Application (React & Material-UI)

A feature-rich, responsive e-commerce front-end application built with modern web technologies, supporting multi-language internationalization (Arabic/English) and dynamic dark/light theme switching.

---

## 🚀 Live Demo
🔗 [View Live Website]https://github.com/mohamedAtef-dev/ecommerce-frontend.git

---

## ✨ Features
* **Responsive UI/UX**: Designed with **Material-UI (MUI)** to look stunning on mobile, tablet, and desktop screens.
* **State Management**: Uses **Redux Toolkit (RTK)** and RTK Query for efficient data handling and shopping cart operations.
* **Multi-Language (i18n)**: Full support for English and Arabic languages with dynamic `dir="rtl/ltr"` switching.
* **Dark & Light Mode**: Custom color palette supporting seamless theme toggling.
* **Interactive Components**: Category filtering, product detail modals, and dynamic search functionality.

---

## 🛠️ Technologies Used
* **React.js** (with TypeScript)
* **Material-UI (MUI)** & Emotion
* **Redux Toolkit** & RTK Query
* **React-i18next** (Localization)
* **Vite** (Build Tooling)
